## Loops

### Loops - help us to execute a block of code multiple times as long as a condition is true.
### Each execution of the loop is called an iteration.
### 4 types of loops 
1. for loop --> allows repeated execution of a block of code based on a specified number of iterations.
    * loops are used to automate repetitive tasks.
    * for loop should be terminated after a specified number of iterations
    * Infinite for  loops are not allowed.
   * Variables initialized in the for loop are available in the loop body, but not outside the loop.
   
2. Nested for loop --> loop defined inside another loop which allows to repeat the actions within the context of the outer loop.
    * nested loop is only executed if the outer loop is executed.
   
3. "while" loop 
   * repeateadly execute a block of code while a specified condition is true.
   * condition is checked before each iteration of the loop 

4. "do-while" loop 
   * repeateadly execute a block of code while a specified condition is true but slightly different from the "while" loop.
   * condition is checked after each iteration of the loop.

## Differences between Looops 
1. if the number of input Iteration is fixed, use "for" loops
2. if the number of iteration is not fixed, use "while" loops
3. if the number of iteration is not fixed and you need to execute the loop bidy at least once, use"do-while" loop
