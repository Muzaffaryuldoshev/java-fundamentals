## Control flow Statement
## Selection Statement --> if, if-else, switch
## Looping statement --> for, while, do-while
## Branching statement --> break, continue, return


### If-Statement --> used for making decisions based on a specific condition
### Types of if-statement 
1. if --> Single Selection 
2. if-else --> Two way Double Selection 
3. if-else-if (Multi branch if)
4. Nested if-statement 


## Selection statements part 2 
### Switch Statement --> used for making decisions based on a specific value amd it executes one statement from multiple conditions

## If vs switch statement
1.  multiple expressions for  multiple choices VS single expression for multiple choices 
2. checks for boolean  expression(equality & inequality) VS checks only for  equality 
3. slower VS faster when the number of if statements is many 
4. code may be complex and hard to read VS code is more concise and readable, easy to edit

### Switch value can be --> byte, short, int, char, String and case value must be the same type as switch value
