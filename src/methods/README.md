## Method  
    * a block of code that does a specific of task
    * it only runs when it is called 
### Why Method?
    * code reusability
    * code readibility 
    * maintinance 
    * easier to maintain 
    * code once, use everywhere
### What do we have in the method creation? 
* access modifiers --> public or  private "determines visibility"
* static modifier --> static "allows to call method by class name"
* return type --> void "if void it doesn't have any return value like string"
* method name --> name() "name always comes with parantheses"
* parantheses and then method body --> (){body}

### Parameters & arguments 
* they are both values that are passed into methods 
* parameter -> public static void displayValue (-> int num <-)
  * they act as placeholder for upcoming value and must have data types 
* argument -> displayValue(-> 5 <-)
  * arguments are actual values and must be given in the paranthese or as a variable 
* **The number and order of arguments must match the number and order of parameters.**

* Returning value -> a way of to provide result or output from method back to the code that called it

### Method Overloading 
* it allows a class to have multiple methods of the same name but different parameters 
  * big 3 of method overloading 
  1. different data types 
  2. different number of parameters 
  3. different order of parameters 
### Why method overloading
*  improved readibility '
* code reusibility 
* easier to maintain
