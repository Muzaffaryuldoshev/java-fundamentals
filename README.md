# Java Fundamentals

Core Java concepts practiced step by step while building toward a QA Automation 
Engineer role. Each package below covers one concept, with a short theory README 
plus hands-on code examples demonstrating it.

Built with plain Java (no build tool) — files can be run directly via IntelliJ 
or `javac`/`java` from the command line.
